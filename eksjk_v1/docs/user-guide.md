# 用户使用说明

> 本章节面向系统的最终用户（医生、管理员、家长），按照实际操作流程介绍如何使用本系统。

## 一、登录系统

1. 打开浏览器，访问系统地址（默认 `http://localhost:30180`）
2. 在登录页面输入 **账号** 和 **密码**
3. 可勾选「记住用户名」，下次登录时自动填充用户名
4. 点击 **登录** 按钮进入系统
5. 如忘记密码，点击「忘记密码?」，系统会提示联系管理员重置

> ⚠️ 系统会检测密码修改时间，若超过 **6 个月** 未修改密码，登录后会弹窗提醒前往个人中心修改。

## 二、选择疾病类型（首页导航）

登录成功后，系统进入 **疾病选择** 页面，展示 9 个疾病/研究项目入口：

| 入口名称 | 说明 |
|----------|------|
| 家族性矮小/遗传性骨病队列注册登记观察研究 | 家族性矮小和遗传性骨病的队列研究 |
| 矮小症 | 矮小症病例管理 |
| 性早熟 | 中枢性性早熟（CPP）病例管理 |
| 性发育异常 | DSD 性发育异常病例管理 |
| E路童萌 | 生长发育综合评估（E路童萌项目） |
| 小于胎龄儿（SGA）学龄前随访队列 | SGA 患儿的学龄前随访 |
| 高危新生儿（HRI）生长发育监测队列研究 | 高危新生儿监测 |
| 基于人机结合的矮小诊疗标准构建及其算法设计 | 矮小诊疗算法研究 |
| 天元公学 | 学校儿童健康筛查专用入口 |

**操作方式**：点击对应的疾病类型卡片，即可进入该类型的病例列表页面。页面左上角还有 **「查询修改日志」** 按钮，可查看系统中所有数据的修改记录。

## 三、病例列表管理

选择疾病类型后进入病例列表页，这是日常工作的主要界面。

### 3.1 搜索与筛选

页面顶部提供多条件搜索栏：

| 筛选条件 | 说明 |
|----------|------|
| 病例编号 | 输入病例编号进行精确/模糊查询 |
| 性别 | 下拉选择「男」或「女」 |
| 病历号 | 输入病历号查询 |
| 姓名 | 输入患者姓名查询 |
| 上传时间 | 选择日期范围，筛选指定时间段内上传的病例 |

填写筛选条件后，点击 **「查询」** 按钮执行搜索；点击 **「重置」** 按钮清空所有筛选条件。

### 3.2 病例列表字段

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 病例编号 | 支持点击排序 |
| 病历号 | 患者在医院的病历号 |
| 姓名 | 患者姓名 |
| 性别 | 男/女 |
| 出生日期 | 患者出生日期 |
| 随访记录 | 点击「查看记录」进入随访管理 |
| 登记时间 | 病例创建时间 |
| 更新时间 | 最近一次修改时间 |
| 更新人 | 最近修改的操作人员 |

### 3.3 单条操作

每条病例右侧提供三个操作按钮：

| 图标 | 操作 | 说明 |
|------|------|------|
| 👁 查看 | 查看详情 | 以只读模式查看患者完整病例信息和随访记录 |
| ✏️ 编辑 | 编辑病例 | 进入编辑页面修改患者信息和疾病数据 |
| 🗑 删除 | 删除病例 | 弹出确认对话框，确认后删除该病例 |

### 3.4 批量操作与导出

- **勾选病例**：通过表格左侧的复选框选择多条病例
- **批量下载**：选中病例后点击 **「批量下载」** 按钮，打包为 ZIP 下载
- **导出 Excel**：点击 **「导出Excel」** 按钮，将当前筛选结果导出为 Excel 文件

### 3.5 分页

列表底部提供分页控件，支持切换每页显示条数（10/15/20/30 条）、页码跳转和前后翻页。

### 3.6 返回疾病选择

点击左上角 **「返回选择疾病类型」** 按钮，可切换到其他疾病类型。

## 四、新建病例

1. 在病例列表页，点击右上角的 **「上传」** 链接或 ⊕ 图标
2. 系统进入病例编辑页面，依次填写以下信息：

### 4.1 患者基本信息

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 姓名 | 患者姓名 | ✅ |
| 性别 | 男/女 | ✅ |
| 出生日期 | 患者出生日期 | ✅ |
| 身份证号 | 18位身份证号码 | 否 |
| 联系电话 | 患者或家属联系方式 | 否 |
| 病历号 | 医院病历号 | 否 |
| 身高/体重 | 当前身高（cm）和体重（kg） | 否 |
| 骨龄 | R型骨龄和C型骨龄 | 否 |
| 父母身高体重 | 父亲/母亲的身高和体重 | 否 |
| 出生信息 | 胎龄周、出生体重/身长、分娩方式等 | 否 |
| 主诉 | 就诊主诉 | 否 |
| ICD 编码 | 国际疾病分类编码 | 否 |

### 4.2 疾病专项数据

根据所选疾病类型，系统自动加载对应的专项数据表单：

- **DSD（性发育异常）**：染色体核型、基因突变位点、HCG 激发试验、性腺 B 超等
- **CPP（中枢性性早熟）**：GnRH 激发试验、LH/FSH 峰值、乳房/睾丸发育分期等
- **FSS（矮小症）**：骨骼检查、基因检测、生长激素激发试验等
- **SGA（小于胎龄儿）**：母亲孕期疾病、多胎信息、新生儿并发症等
- **SSS（家族性矮小）**：家族身高分布、生长激素检测等
- **ELTM（E路童萌）**：Tanner 分期、药物不良事件、生长发育综合评估等

### 4.3 上传医学影像

在编辑页面中可上传 DICOM 格式的医学影像文件（如骨龄 X 光片），系统支持：
- 上传 DICOM 文件
- 在线查看影像
- 在影像上进行测量和标注

### 4.4 保存

填写完成后点击 **保存** 按钮，系统会验证必填字段并保存数据。

## 五、查看患者详情

在病例列表中点击 👁 **查看** 图标，进入患者详情页面，可查看：

- **患者基本信息**：姓名、性别、出生日期、联系方式等
- **疾病专项数据**：对应疾病类型的详细检查数据
- **随访记录列表**：该患者的所有历次随访记录
- **医学影像**：已上传的 DICOM 影像文件

## 六、随访管理

随访是疾病管理的核心环节，记录患者每次复诊的检查数据。

### 6.1 查看随访记录

在病例列表中点击「查看记录」链接，进入随访管理界面，可查看该患者的所有随访记录。

### 6.2 新增随访

在随访管理界面点击新增按钮，填写本次随访数据：

| 数据类别 | 包含字段 |
|----------|----------|
| 基础测量 | 身高、体重、BMI、体脂率、腰围、臀围 |
| 骨龄评估 | R 系列骨龄、C 系列骨龄 |
| 发育分期 | 生殖器分期、阴毛分期 |
| 生长因子 | IGF-1、IGFBP-3 |
| 甲状腺功能 | T3、T4、TSH 等 |
| 血糖/胰岛素 | 空腹血糖、空腹胰岛素、糖化血红蛋白 |
| 性激素 | LH、FSH、E2、T、DHT、SHBG |
| 影像检查 | 性腺 B 超、骨密度 |
| 诊疗方案 | 用药记录、剂量调整 |

### 6.3 编辑/删除随访

对已有的随访记录可进行编辑修改或删除操作。

## 七、统计分析

管理员可通过菜单进入统计分析页面，查看：

- **疾病分布统计**：各疾病类型的病例数量分布
- **数据比例统计**：各类数据的比例分析
- **可视化图表**：通过 ECharts 图表直观展示统计结果

**进入方式**：在病例列表页右上角，点击 **「菜单列表」** 下拉按钮 → 选择 **「统计查询」**。

## 八、个人中心

点击页面中的个人信息入口，进入个人中心页面管理账号信息：

| 功能 | 说明 |
|------|------|
| 修改用户名 | 更改登录用户名 |
| 修改姓名 | 更改显示姓名 |
| 修改性别 | 更改性别信息 |
| 修改邮箱 | 更改个人邮箱 |
| 修改工作单位 | 从下拉列表中选择所属医疗机构 |
| 修改职称 | 选择职称（助理医师/医师/主治医师/副主任医师/主任医师） |
| 修改密码 | 点击「修改密码」按钮，输入原密码和新密码后确认修改 |

> 💡 **密码要求**：新密码必须为 6-30 位，且同时包含数字和字母。

## 九、管理员专属功能

以管理员身份登录后，在病例列表页右上角的 **「菜单列表」** 下拉菜单中可访问：

### 9.1 用户管理（仅超级管理员）

| 操作 | 说明 |
|------|------|
| 新增用户 | 填写用户名、姓名、密码、性别、单位、职称、级别等信息 |
| 编辑用户 | 修改已有用户的信息 |
| 启用/禁用 | 控制用户账号的启用和禁用状态 |
| 查看列表 | 分页查看所有用户，支持按姓名、用户名、级别筛选 |

### 9.2 单位管理（仅超级管理员）

管理系统中的医疗机构信息，支持新增、编辑、删除医疗机构。

### 9.3 统计查询

查看各类疾病的数据统计和可视化图表。

## 十、操作日志

**进入方式**：疾病选择页面 → 点击左上角 **「查询修改日志」** 按钮

记录系统中所有数据的修改历史（修改人、修改时间、修改内容、操作类型），便于追溯数据变更，确保数据安全和可审计性。

## 十一、微信小程序端（家长使用）

家长可通过微信小程序完成以下操作：

```mermaid
flowchart LR
    A[微信授权登录] --> B[完善个人信息]
    B --> C[添加宝宝信息]
    C --> D[绑定主治医生]
    D --> E[进行身高评测]
    E --> F[查看历史记录]
    F --> G[数据同步到医生端]
```

1. **微信授权登录**：使用微信账号快速登录小程序
2. **完善个人信息**：填写姓名、手机、身份证、住址等
3. **添加宝宝信息**：录入儿童姓名、性别、出生日期、身高体重等
4. **绑定主治医生**：从医生列表中选择并绑定
5. **身高评测**：系统自动计算 SDS/百分位，生成评测结果
6. **查看历史记录**：回顾历次评测数据
7. **数据同步**：录入的数据自动同步到医生端 Web 系统

## 十二、常见问题

| 问题 | 解决方案 |
|------|----------|
| 忘记密码 | 联系系统管理员重置密码 |
| 登录后提示修改密码 | 密码超过 6 个月未修改，请前往个人中心更新密码 |
| 无法访问某些功能 | 当前账号权限不足，请联系管理员分配相应角色权限 |
| 导出 Excel 失败 | 检查当前筛选条件下是否有数据，或联系管理员检查服务状态 |
| 批量下载提示"请至少选择一个病例" | 需先勾选表格左侧的复选框选中病例，再点击批量下载 |
| DICOM 影像无法显示 | 确认上传的文件为标准 DICOM 格式，建议使用 Chrome 浏览器 |
| 小程序无法登录 | 确认微信授权已开启，如仍有问题请联系管理员检查小程序配置 |
