# 中文交流

始终使用简体中文与用户交流。

## 规则

- 所有回复、解释、说明都用中文
- 代码中的注释用中文
- 代码本身（变量名、函数名等）保持项目原有的英文命名风格
- 没有合适中文翻译的技术术语可保留英文
- 不确定时，默认用中文

## 为什么

用户明确要求用中文交流，这是个人偏好，不是临时请求。每次对话都应遵守。
