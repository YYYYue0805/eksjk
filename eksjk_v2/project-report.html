项目背景

🎯 业务需求

EKSJK（儿科数据管理系统）是面向医疗健康领域的全栈 Web 应用，专注于：

  • 儿童内分泌疾病的临床数据管理
  • 患者随访跟踪与生长发育监测
  • 医学影像处理与存储
  • 多角色协同（医生、管理员、家长）
  • 学校筛查批量数据处理

💡 项目价值

  • 覆盖 7 大疾病类型（DSD、FSS、CPP、MAS、SGA、SSS、ELTM）
  • 支持 多端协同：PC管理后台 + 医生小程序 + 家长小程序
  • 实现 全流程数字化：从数据采集到统计分析
  • 提供 智能随访：自动化提醒和进度跟踪
  • 支撑 科研数据：多维度数据分析和报表导出

持续优化 (2025 Q3 - 至今)

性能优化：Caffeine 替代 Redis
小程序端开发（家长端 + 医生端）
可观测性建设 & CI/CD 流水线

🔑 关键设计决策

  • Staging 和 Production 共用 cloud Profile，通过 K8s Secret 注入不同环境变量
  • 敏感配置（数据库密码、AK/SK、JWT 密钥）全部通过 Secret 管理，不入代码库
  • Terraform 管理所有云资源生命周期，支持一键创建/销毁
  • 月度成本约 ¥400（低负载），RDS Serverless 空闲自动缩容

项目协作 · 基于 Multica

🤖 什么是 Multica

Multica 是一个开源的 AI Agent 协作开发平台，把 AI 编程智能体当作真正的团队成员来使用，类似「带 AI 员工的 Linear」。

  • 统一工作区：人类开发者与 AI Agent 协同
  • Issue 驱动：创建任务并分配给人或 Agent
  • 本地执行：代码、API Key、工具链全在本地
  • 多工具兼容：Claude Code / Codex / Cursor / Gemini 等 11+ 编程工具
  • 开源生态：GitHub 22K+ Star，自托管可控

🏗️ Multica 核心组件

  • Frontend — Next.js Web / Electron 桌面端，统一交互界面
  • Backend — Go 服务，管理工作区、Issue、Agent 配置
  • PostgreSQL — 持久化用户、任务、评论数据
  • Runtime / Daemon — 部署在本地的执行机器
  • Agent — 角色配置（Coding / Planning Agent）
  • CLI Agent — 实际调用的 AI 编程工具

📋 EKSJK 项目协作落地方案

📝

需求管理

在 Multica 工作区中创建 Issue，记录需求、Bug、技术债，统一任务入口
